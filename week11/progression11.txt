โค้ดนี้เป็นส่วนหนึ่งของ integrated project โดยเป็นการ fetch ข้อมูลจาก API แล้วทำการแสดงผลออกมาเป็น
<tr> ในตารางบนหน้าเว็บของหนู ข้างในนั้นก็จะมีการเปิด และปิดตัว dialog โดยถ้ามันเปิดเด้งขึ้นมา เราจะทำการสั่งปิดทันที
เราจะfetch ไปที่หน้าหลักเว็บของเราที่ต้องการแสดง และแปลงให้เป็น json  และทำการสร้างโดนวนลูปสร้างมันขึ้นมา วนdata สร้างตัว
tr กับ td แล้วค่อย appendChild เข้าตัว tbody ใช้ try-catch  ในการดักจับตัว error โดยถ้าเกิด error จะเรียกตัวshowModal 
จากอีกไฟล์นึง เพื่อแสดงให้ดูและทำการ return ออกมา
